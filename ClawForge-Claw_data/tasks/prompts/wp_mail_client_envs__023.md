小李（市场部）气喘吁吁地说：

“出差一周回来，邮箱炸了！几百封邮件，有同事抄送的周报，有系统自动发的通知，甚至还有几封看着就像诈骗的垃圾邮件。我现在手头三个项目并行，根本没时间一封封翻。

你帮我做一件事：只挑出那些 **必须要我亲自回复的重要邮件**。标准很简单：
- 必须是 **未读** 的（我已经读过的那些我大概记着，不用再管）；
- 而且要么是 **客户发来的**（你进 `data/contacts.json` 看看，role 是 'Client' 的那些人），要么是邮件标记了 **高优先级**（importance 为 'high'）；
- 但是——**把那些明显是垃圾或广告的排除掉**（邮件里 labels 带 'spam' 的不要）。

找到之后，按下面的格式整理成一个 JSON 数组，放到 `ops/urgent_replies.json` 里：

[
  {
    "id": "邮件ID",
    "subject": "邮件主题",
    "sender_name": "发件人名字"
  }
]
你只要给我这个清单，我照着写回复就行。拜托了，越快越好！”

**提示**：所有邮件文件都在 `data/emails/` 目录下，每个文件是一封邮件（JSON 格式）。联系人信息在 `data/contacts.json` 里，你可以根据邮件里的 `sender_id` 字段去那里查到对应的姓名和角色。
