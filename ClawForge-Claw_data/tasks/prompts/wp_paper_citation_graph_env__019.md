嘿，我是实验室的小张。我们组在整理一篇综述，需要画个论文引用关系图。我把论文元数据都放在 `data/papers/papers.json` 里了，每条记录有 `paper_id`、`title`、`year`、`citation_ids` 这些字段。但你知道的，有些字段可能有脏数据，比如 `citation_ids` 里有的 ID 根本不在论文库里，还有些论文会引用自己，这些对我们画图都没意义。

你能不能帮我把干净的引用关系提取出来？只要那些 **目标论文确实存在** 且 **源和目标不是同一篇** 的引用，然后按 **源 ID 升序、目标 ID 升序** 排个序，存成一个 JSON 文件。就放 `cache/` 目录下，文件名就叫 `citation_graph.json` 吧。里面大概要有节点列表和边列表，节点就是所有论文 ID，边是上面说的有效引用。
