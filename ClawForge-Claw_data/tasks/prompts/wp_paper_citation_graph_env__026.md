我最近在梳理我们实验室的论文引用关系，做可视化用。我把每篇论文的摘要信息都整理成了 JSON 文件，放在 `data/papers/` 下面，文件名就是论文 ID，比如 `p001.json`、`p002.json` 这样。但是项目目录里混了不少乱七八糟的东西——有 `.bak` 的备份文件，还有一些无关的 JSON 文件（比如 `temp.json`），这些你直接忽略就好，别管它们。

另外，我注意到有些论文里居然引用了自己，或者引用了不存在的论文 ID——这种边肯定是无效的，不要算进去。还有一些引用是重复的（比如同一篇论文在不同的备份里出现），你只需要每个论文 ID 处理一次就行，最终边要去重。

你帮我把所有论文之间**真实有效的引用关系**挑出来，生成一个干净的图快照，放在 `output/citation_graph.json` 里。格式要这样：
{
  "edges": [
    {"source": "p001", "target": "p002"}
  ]
}
边要按照 source 升序排列，同一个 source 下按照 target 升序排列。
