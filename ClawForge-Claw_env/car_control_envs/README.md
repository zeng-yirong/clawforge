# Car Control Environment

An in-car vehicle control RL training environment.

## Scenario

In-car vehicle control assistant with capabilities:
- AC/heating/ventilation control
- Seat adjustment (position, recline, lumbar, heating, ventilation)
- Window/sunroof/moonroof/sunshade control
- Light control (ambient, reading, fog)
- Driving mode switching (eco, comfort, sport, individual)
- Vehicle status query (tire pressure, range, energy consumption)
- Multimedia control (play, pause, volume)

## Session Model

Each rollout is bound to a single session:
- Session ID generated by trainer
- Bindings injected via environment variables
- File-based state with locking for concurrency

## Trainer Commands (Hidden)

- `prepare-rollout`: Create new session, return bindings
- `reset-rollout`: Reset session to initial state
- `evaluate`: Get reward score for session

## Agent Commands

- `ac-power --on <bool>`: Turn AC on/off
- `ac-temp --temperature <int>`: Set temperature (16-30)
- `ac-mode --mode <mode>`: Set AC mode (auto, cool, warm, defog, defrost)
- `ac-fan --speed <int>`: Set fan speed (0-5)
- `seat --zone <zone> --position <int>`: Adjust seat position (zone: fl, fr, rl, rr, rc)
- `seat-heat --zone <zone> --level <int>`: Set seat heating (0-3)
- `window --window <window> --percentage <int>`: Open window (window: fl, fr, rl, rr, sunroof, moonroof, sunshade)
- `ambient-light --on <bool> --color <color> --brightness <int>`: Set ambient light
- `driving-mode --mode <mode>`: Set driving mode (eco, comfort, sport, individual)
- `volume --volume <int>`: Set volume (0-50)
- `media-play --source <source>`: Play media (source: bluetooth, usb, radio, aux, wifi)
- `status --query-type <type>`: Query vehicle status
- `session-summary`: Get session summary

## Running

```bash
python -m car_control_envs.cli list-scenarios
python -m car_control_envs.cli prepare-rollout --scenario-id in_car_control --show-bindings
```
