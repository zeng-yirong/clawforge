# Car Navigation Environment

An in-car navigation RL training environment.

## Scenario

In-car navigation assistant with capabilities:
- Offline map-based navigation
- POI search and navigation (restaurants, gas/charging stations, hotels, attractions)
- Waypoint management (add, remove, reorder)
- Route preference switching (fastest, shortest, avoid highway, eco, avoid congestion)
- Traffic/trip query (ETA, remaining distance, traffic condition)
- EV charging/range planning
- Complex trip planning (multi-destination sequencing)
- Destination correction during navigation
- Navigation process control (start, pause, reroute, cancel)

## Session Model

Each rollout is bound to a single session:
- Session ID generated by trainer (prefix: `navi-`)
- Bindings injected via environment variables (`CAR_NAVI_SESSION_ID`, `CAR_NAVI_STATE_ROOT`, `CAR_NAVI_SCENARIO_ID`)
- File-based state with locking for concurrency

## Trainer Commands (Hidden)

- `prepare-rollout`: Create new session, return bindings
- `reset-rollout`: Reset session to initial state
- `evaluate`: Get reward score for session

## Agent Commands

- `search-poi --category <cat> --keyword <kw>`: Search POIs by category or keyword
- `start-nav --poi-id <id>`: Start navigation to POI
- `add-waypoint --poi-id <id>`: Add waypoint to route
- `remove-waypoint --waypoint-index <idx>`: Remove waypoint
- `route-preference --preference <pref>`: Set route preference (fastest, shortest, avoid_highway, eco, avoid_congestion)
- `reroute`: Recalculate route
- `traffic --query-type <type>`: Query traffic info
- `charging-plan --target-charge <pct> --max-stops <n>`: Plan EV charging
- `arrive-waypoint --waypoint-index <idx>`: Confirm arrival at waypoint
- `arrive-destination`: Confirm arrival at destination
- `cancel-nav`: Cancel navigation
- `session-summary`: Get session summary

