# Expense Management Environment

An offline expense management and budget analysis RL training environment.

## Scenario

Expense reimbursement analysis based on company travel policy:
- Load travel policy based on employee tier
- Calculate expense budgets for transportation, accommodation, meals
- Load actual consumption records from business trips
- Generate budget vs actual analysis
- Identify over-budget items
- Export summary reports

## Session Model

Each rollout is bound to a single session:
- Session ID generated by trainer (prefix: `exp-`)
- Bindings injected via environment variables (`EXPENSE_SESSION_ID`, `EXPENSE_STATE_ROOT`, `EXPENSE_SCENARIO_ID`)
- File-based state with locking for concurrency

## Trainer Commands (Hidden)

- `prepare-rollout`: Create new session, return bindings
- `reset-rollout`: Reset session to initial state
- `evaluate`: Get reward score for session

## Agent Commands

- `load-policy --tier <tier>`: Load travel policy (standard, senior, executive)
- `calculate-budget --tier <tier> --destination <dest> --duration-days <n>`: Calculate budget
- `load-consumption --trip-id <id>`: Load consumption records
- `generate-analysis`: Generate budget vs actual analysis
- `export-report`: Export expense summary report
- `session-summary`: Get session summary

## Running

```bash
python -m expense_envs.cli list-scenarios
python -m expense_envs.cli prepare-rollout --scenario-id expense_analysis_001 --show-bindings
```
