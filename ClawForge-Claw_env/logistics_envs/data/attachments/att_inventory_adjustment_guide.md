# Inventory Adjustment Guide

## When to Adjust Inventory

Inventory adjustments are required when:
- Physical count differs from system records
- Damage or spoilage occurs
- Theft or loss is discovered
- Items are used internally
- System errors are corrected

## Reason Codes

| Code | Description | Requires Manager Approval |
|------|-------------|---------------------------|
| DAMAGE | Physical damage to items | No |
| THEFT | Suspected theft | Yes |
| EXPIRED | Items past expiration | No |
| INTERNAL_USE | Used for operations | Yes |
| SYSTEM_CORRECTION | Data entry error fix | No |
| RECOUNT | Physical audit correction | No |
| RETURN Damaged | Customer returned damaged item | No |

## Adjustment Process

### Step 1: Identify Discrepancy
- Compare physical count to system quantity
- Document SKU, warehouse, and difference

### Step 2: Determine Reason Code
- Select appropriate reason code from table above
- If uncertain, escalate to supervisor

### Step 3: Submit Adjustment
- Use inventory adjustment form
- Include:
  - SKU
  - Warehouse ID
  - Quantity change (+/-)
  - Reason code
  - Supporting documentation
  - Employee ID

### Step 4: Manager Review (if required)
- Refund over $100 adjustments auto-flag for review
- Manager approves within 48 hours

## Reconciliation Reports

Generate reconciliation reports:
- Weekly: All warehouses
- Daily: High-value SKUs
- On-demand: Specific warehouse or SKU

Report includes:
- Expected vs actual quantities
- Value of discrepancy
- Trend analysis
- Recommended actions
