# Music Player Environment

An in-car music assistant RL training environment.

## Scenario

In-car music system with voice assistant capabilities:
- Basic on-demand playback by song name, artist, album, brand/OST theme
- Tag/condition-based search: scene tags, style, language, era, crowd, charts, similar songs
- Playback control: play, pause, next, previous, seek, mode switch, player selection
- Current playback status query

## Session Model

Each rollout is bound to a single session:
- Session ID generated by trainer
- Bindings injected via environment variables
- File-based state with locking for concurrency

## Trainer Commands (Hidden)

- `prepare-rollout`: Create new session, return bindings
- `reset-rollout`: Reset session to initial state
- `evaluate`: Get reward score for session

## Agent Commands

- `status`: Get current playback status
- `play --song-id <id>`: Play a song
- `pause`: Pause playback
- `resume`: Resume playback
- `next`: Next track
- `previous`: Previous track
- `seek --position <sec>`: Seek to position
- `set-mode --mode <mode>`: Set play mode
- `switch-player --player <name>`: Switch audio player
- `list-songs`: List all songs
- `list-playlists`: List all playlists
- `list-players`: List available players
- `search`: Search songs with filters
- `session-summary`: Get session summary

## Running

```bash
python -m music_player_envs.cli list-scenarios
python -m music_player_envs.cli prepare-rollout --scenario-id music_in_car --show-bindings
```
