# Category Review Template

The cached same-category competitor report should include:

1. Target brand and category identification.
2. Target SKU coverage count.
3. Competitor brand coverage for the same category.
4. Pricing comparison using the approved current price book.
5. Reusable structured fields for selling-point and ingredient comparison.

A report that omits the target brand, omits competitor coverage, or uses an archived price book is incomplete.
